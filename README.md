# J.A.R.V.I.S. для macOS

Голосовой ассистент и системный монитор для Mac в стиле интерфейса Железного человека. Говорит и понимает по-русски.
Нейросетевой голос работает прямо на маке, без интернета. Есть дашборд на весь экран, виджет на рабочий стол
и маленький Марк-0, который живёт поверх окон.

> Неофициальный фан-проект. Не связан с Marvel и The Walt Disney Company. Названия J.A.R.V.I.S. и Iron Man
> принадлежат их правообладателям.

## Что умеет

**Системный монитор.** Индекс здоровья мака, ядра процессора (P и E), видеоядро, температура, память, диски и
скорость чтения и записи, сеть с пингом, VPN, защита (FileVault, брандмауэр, SIP, Gatekeeper), периферия и её
батарея, советы, что почистить.

<img src="docs/media/widget.png" alt="Виджет" width="260" align="right">

**Голос.** Слово-активатор «Джарвис». Нейросеть Silero говорит локально, у неё 10 эмоций, от них меняются
интонация и цвет реактора. В голосовой лаборатории выбираются голос, обработка («Шлем», «Голограмма», «Старый»),
высота и темп.

**Команды.** Открыть или закрыть любую программу, громкость, музыка, скриншот, блокировка, сон, погода, таймеры
и помидоры, напоминания, поиск файлов, протоколы («фокус», «вечеринка», «призрак»), свои команды в JSON.

**Плагины** (папка `plugins/`, одно умение на файл):

| Плагин | Что делает |
| --- | --- |
| `agenda` | События из Календаря, расширенный утренний брифинг |
| `context` | Активное окно, история буфера, «что на экране» (нужен ключ API) |
| `projects` | Статус git-проектов, «открой проект …» в Cursor, VS Code или Xcode |
| `guard` | Страж: новые автозапуски, программы, открывшие порт в сеть, место на диске, обновления macOS |
| `files` | Поиск по содержимому файлов через Spotlight, разбор Загрузок по папкам с откатом |
| `focus` | Молчит, пока ты долго работаешь в редакторе или сидишь в звонке |
| `daily` | Итоги дня и недели, вечерний отчёт |
| `habits` | Вода и любые свои привычки, напоминания |
| `notes` | Быстрые заметки голосом в `~/JARVIS/Заметки.md` |
| `music` | «Что играет», плейлисты Apple Music по названию и настроению |
| `windows` | Окно влево, вправо, на весь экран, по центру |
| `shortcuts` | Запуск быстрых команд macOS, через них умный дом и HomeKit |
| `services` | Мониторинг своих сайтов, тревога, если сайт лежит |
| `appearance` | Шесть тем оформления дашборда и виджета |
| `doctor` | «Почему ты молчишь», самодиагностика |
| `say_api` | HTTP-вебхук и скрипт `jarvis-say`: другие программы могут говорить голосом Джарвиса |
| `memory_cmds`, `plugin_admin` | Долговременная память, включение и отключение плагинов голосом |

**Шесть тем оформления**: голубая, красная, золотая, зелёная, фиолетовая, ледяная. Меняются голосом: «тема красная».

![Темы оформления](docs/media/themes.jpg)

**Мозг на LLM (по желанию).** Если ни одна команда не подошла, запрос уходит в Claude. Он понимает свободную
речь, помнит факты о тебе и сам вызывает инструменты: команды Джарвиса, календарь, проекты, буфер, экран,
а также внешние MCP-серверы. Без ключа API всё остальное работает как обычно.

## Требования

- Mac на Apple Silicon (M1 и новее). Проверено на macOS 27, должно работать начиная с macOS 13.
- Python 3.11 или новее, лучше с [python.org](https://www.python.org/downloads/macos/).
- Command Line Tools for Xcode (`xcode-select --install`), чтобы собрать нативное приложение.
- Около 1 ГБ на диске для голосовой нейросети: torch и модель Silero ставятся автоматически при первом запуске.
- Микрофон для голосовых команд: встроенный, AirPods, гарнитура или веб-камера. Без микрофона команды можно
  писать в строку на дашборде или в виджете.

## Установка

```bash
git clone https://github.com/Komalangi/jarvis-mac.git ~/Desktop/JARVIS
python3 ~/Desktop/JARVIS/jarvis.py
```

При первом запуске соберётся приложение `~/Applications/JARVIS.app`, а голос подготовится за пару минут.
Дальше JARVIS открывается через Spotlight (Cmd+Пробел → JARVIS) или по иконке реактора в строке меню.

После правок в коде приложение нужно пересобрать:

```bash
python3 ~/Desktop/JARVIS/jarvis.py --rebuild
```

### Разрешения macOS

macOS попросит их при первом использовании. После пересборки может спросить ещё раз, это нормально.

| Разрешение | Зачем |
| --- | --- |
| Микрофон и распознавание речи | Голосовые команды |
| Универсальный доступ | Окна, вставка текста, кнопка VPN |
| Автоматизация (System Events, Calendar, Music) | Звук, блокировка, календарь, плейлисты |
| Запись экрана | Скриншоты и «что на экране» |

### Подключить мозг (необязательно)

Нужен [ключ API Anthropic](https://console.anthropic.com/). Он хранится в Связке ключей macOS, а не в файлах:

```bash
security add-generic-password -U -s jarvis-anthropic -a jarvis -w
```

Команда спросит ключ. Перезапусти JARVIS и скажи «Джарвис, настрой мозг». Модель и своё имя можно указать
в `~/Library/Application Support/JARVIS/brain.json`:

```json
{"enabled": true, "model": "claude-sonnet-5-5", "user_name": "Имя"}
```

## Как пользоваться

Скажи «Джарвис», дождись звука, потом говори команду. Полный список подскажет «Джарвис, что ты умеешь?».
Все команды и настройки собраны в [руководстве](docs/GUIDE.md).

| Клавиши | Действие |
| --- | --- |
| Option+Command+J | Развернуть дашборд или свернуть в виджет |
| Esc | Свернуть дашборд в виджет |

## Настройка

Все личные настройки живут вне репозитория, в `~/JARVIS` и `~/Library/Application Support/JARVIS`:

| Файл | Что внутри |
| --- | --- |
| `~/JARVIS/Мои команды.json` | Свои голосовые команды: `app:`, `url:`, `folder:`, `file:`, `say:` |
| `~/JARVIS/Мои реплики.json`, `Мои реплики Марка.json` | Свои реплики поверх стандартных |
| `~/JARVIS/Произношение.json` | Как читать вслух слова и названия |
| `~/JARVIS/Каналы.json` | Каналы на Дзене для заказа статей и обложек через Claude |
| `~/JARVIS/Сервисы.json` | Сайты для мониторинга |
| `~/JARVIS/mcp.json` | MCP-серверы для мозга |
| `Application Support/JARVIS/brain.json` | Модель и имя для мозга |
| `Application Support/JARVIS/projects.json` | Папки с git-проектами и редактор |
| `Application Support/JARVIS/music.json` | Плейлисты под настроение |
| `Application Support/JARVIS/plugins_off.json` | Отключённые плагины |

## Свои плагины

Плагин — это файл `plugins/имя.py` с функцией `register(api)`:

```python
def register(api):
    api.command(r"привет,? марк", lambda raw, t, m: "Привет! Марк-0 на связи.")
    api.tool("dice", "Бросить кубик.", None, lambda: str(__import__("random").randint(1, 6)))
```

Подробно об API, фоновых задачах, HTTP-маршрутах и MCP — в [docs/PLUGINS.md](docs/PLUGINS.md).

## Приватность и безопасность

- Сервер слушает только `127.0.0.1`. Все команды, которые что-то меняют, требуют токен из
  `~/Library/Application Support/JARVIS/token`.
- Голос, распознавание речи и все плагины работают локально. В интернет уходят только погода, пинг для проверки сети,
  проверка сайтов из твоего списка и, если ты подключил мозг, запросы к API Anthropic.
- История буфера хранится только в памяти. Её не пишут, пока на переднем плане менеджер паролей.
- Через мозг нельзя выключить мак, перезагрузить его или удалить файлы. Из инструментов MCP мозгу видны только те,
  что перечислены в `allow`.

## Разработка

```bash
python3 -m unittest discover -s tests          # тесты
JARVIS_DEMO=1 python3 jarvis.py               # демо-режим с ненастоящими данными: http://127.0.0.1:7777
```

| Файл | Что внутри |
| --- | --- |
| `jarvis.py` | Ядро: датчики, команды, события, HTTP-сервер, сборка приложения |
| `jarvis_sense.py` | Датчики полного дашборда |
| `jarvis_voice.py` | Синтез речи, эмоции, звуковые эффекты |
| `jarvis_brain.py` | Мозг на LLM, инструменты, память |
| `jarvis_plugins.py` | Загрузчик плагинов |
| `jarvis_mcp.py` | MCP-клиент |
| `JARVISApp.swift` | Нативная оболочка: окна, распознавание речи, строка меню |
| `ui.html`, `widget.html`, `pet.html` | Дашборд, виджет, Марк-0 |
